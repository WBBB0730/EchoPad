# send-files

**发送文件**

## Problem Statement

用 EchoPad 操作电脑时，手机和电脑之间常常要传图片和文件：手机拍的照片、收到的文件要放到电脑上处理，电脑上的截图、文档要发到手机上转给别人。现在只能借助聊天软件给自己发、或者用数据线。剪贴板同步只管文字；图片和文件在手机上也很少有地方能粘贴，常见的做法是存进相册或"下载"，再从分享菜单发出去。

## Solution

手机端和电脑端之间可以手动发送文件，图片、视频也按文件发。手机端在分享菜单里选"同步到 EchoPad"，或者点"发送文件"选文件，或者点"发送剪贴板"发剪贴板里的文件，文件发到当前电脑：存进"下载"文件夹，同时放进电脑剪贴板，直接就能粘贴。电脑端在某部在线手机的卡片上点"发送文件"选文件，或者直接把本机文件拖进首页窗口，或者在访达里复制文件（或者截图到剪贴板）后点它的"发送剪贴板"，文件发到这部手机：图片和视频存进"EchoPad"相册，其他文件存进"下载"。文件从不自动发送；发剪贴板里的文件以及拖进窗口的文件前先确认。手机端的通知栏显示进度，可以取消。

## User Stories

1. 作为用户，我希望在手机相册或文件管理器里选一个或几个文件，从分享菜单发到我正在用的电脑上。
2. 作为用户，我希望电脑收到的文件存进"下载"文件夹，同时已经复制好，直接粘贴到聊天软件、访达或文档里。
3. 作为用户，我希望在电脑上复制几个文件（或者把截图复制到剪贴板），点一下"发送剪贴板"就发到手机上。
4. 作为用户，我希望不熟悉复制和分享菜单时，在 EchoPad 手机端和电脑端里点"发送文件"，直接挑文件发出去。
5. 作为用户，我希望直接把访达里的文件拖进电脑端窗口，发给拖到的那部手机。
6. 作为用户，我希望手机收到的图片和视频直接出现在相册里，其他文件出现在"下载"里。
7. 作为用户，我希望用"发送剪贴板"发文件之前先看到要发几个、多大，确认后才发，免得把没想到的大文件发出去。
8. 作为用户，我希望传大文件时在手机通知栏看到进度，可以随时取消。
9. 作为用户，我希望传文件时触控板照常跟手，不受影响。
10. 作为用户，我希望传完以后看到结果：发到了哪台电脑、存到了哪里，或者失败的原因。
11. 作为用户，我希望文件从不自动发送，只在我主动操作时才传。
11. 作为用户，我希望只有配对过的设备能收发文件，局域网里的其他设备既发不进来，也看不到我传的内容。

## Implementation Decisions

- 发送文件和剪贴板同步分开：文字进剪贴板，自动或手动同步给所有在线的设备（docs/prd/clipboard-sync.md）；文件存到磁盘，只能手动发，不转发，也不受剪贴板同步的两个开关影响。
- 发给谁：
  - 手机端发给当前电脑。当前电脑不在线时不发，提示"某某 不在线"。
  - 电脑端发给用户选的那部手机：主窗口里每部在线手机的卡片上、菜单栏菜单里每部在线手机的一组里，各有"发送剪贴板"和"发送文件"。不另设发给所有手机的按钮：通常只有一部手机在线。
- 入口：
  - 手机端分享菜单里的"同步到 EchoPad"：选中的是文字就同步剪贴板，是文件就发送文件；可以一次选多个文件；不用确认。
  - 两端的"发送文件"：电脑端在每部在线手机的卡片上和菜单栏菜单里（菜单里写"发送文件到 某某…"），打开系统的选文件面板；手机端在 EchoPad 顶部（当前电脑在线时才有），打开系统的文件选择器。都可以多选，不能选文件夹，选完直接发，不用确认。
  - 电脑端拖文件到主窗口：只在首页、有在线手机且没有弹窗打开时生效，仅支持从访达、桌面等拖入的本机文件。只有 1 部手机在线时，拖到窗口任意位置都能发；有多部手机在线时，拖到对应在线手机卡片上发。松手后先弹和"发送剪贴板"一样的系统确认框（写明个数、总大小和目标手机），确认后才发；全是文件夹或读不了文件时直接提示对应错误。
  - 两端的"发送剪贴板"（docs/prd/clipboard-sync.md）：剪贴板里是文件时先弹确认，写明个数、总大小和发给谁（"把 3 个文件（12.4 MB）发送到 小米手机？"，按钮"取消"和"发送"），确认后才发。电脑端剪贴板里的文件来自访达的复制，或者截图等直接放进剪贴板的图片（存成 PNG 发送）；手机端来自相册等应用的"复制"。
  - 不支持文件夹：剪贴板里只有文件夹时提示"不能发送文件夹"，和文件混在一起时只发文件。要发的文件读不了（例如所在的磁盘已经推出）时提示"读不了要发送的文件"。
  - 电脑端确认后提示"正在发送到 小米手机"，手机端接着在通知栏下载；这部手机已经离线时提示"这部手机不在线"。
- 文件到了以后：
  - 电脑端存进当前用户的"下载"文件夹，同时把这一批文件放进剪贴板，效果和在访达里复制这些文件一样；只有一张图片时，剪贴板里另放一份图片数据，方便粘贴到只认图片的地方。用系统通知提示"收到 3 个文件，已复制到剪贴板"。
  - 手机端图片和视频存进相册里的"EchoPad"相册，其他文件存进"下载"。结果通知按存放的地方分条，写明存到了哪里（"已保存 3 个文件到相册""已保存 2 个文件到下载"）：相册那条只有一个文件时点了用相册打开它，多个时打开"Pictures/EchoPad"文件夹；"下载"那条点了打开"下载"文件夹。文件夹用系统自带的"文件"应用打开：WPS、网盘这些应用也声称能打开文件夹，不指定就会先弹选择框。Android 没有打开某个相册、或者在文件夹里选中某个文件的公开接口。
- 提示：传完、失败两端都提示，用户取消的两端都不提示。
  - 手机端发文件：手机端提示"已发送 3 个文件到 某某"或"没能发送到 某某"；电脑端收全时提示"收到 3 个文件，已复制到剪贴板"，没收全时提示"接收中断，已保存 2 个文件"或"没能接收文件"。
  - 电脑端发文件：手机端提示"已保存 3 个文件""接收中断，已保存 2 个文件"或"没能接收文件"；手机端处理完这份清单后把结果告诉电脑端，电脑端提示"小米手机 已保存 3 个文件""小米手机 接收中断，已保存 2 个文件""小米手机 没能接收文件"，手机端不能接收文件时提示"小米手机 的系统版本太低，不能接收文件"。
  - 手机端的结果同时用结果通知和 Toast：结果通知在系统允许时才弹横幅（澎湃 OS 只给白名单里的应用弹），Toast 哪里都看得到。电脑端用系统通知。
  - 重名时在文件名后加序号，例如"截图 (1).png"。
  - 传到一半的文件不出现在"下载"和相册里：电脑端先写临时文件、传完再改名；手机端先标记为未完成、传完再放出来。失败或取消时删掉。
- 传输（ADR-0021）：
  - 文件不走现有的连接，而是在电脑端同一个端口上另发 HTTPS 请求，手机端带上设备密钥证明自己已配对，并照常核对证书指纹（ADR-0014）。传大文件时现有连接上的触控、打字照常收发。
  - 手机端发文件：把一批文件放进一个上传请求，边读边传，电脑端边收边写磁盘，没有大小上限。分享来的文件只在分享页面开着时读得到，手机端趁那时打开，页面关掉以后照样传完。
  - 电脑端发文件：电脑端不能主动连手机端（ADR-0015），先通过现有连接告诉手机端有哪些文件（名称、大小），手机端再逐个下载。每个文件只能下载一次，断线后整份清单作废；截图这类没有文件的内容由电脑端转成 PNG 留在内存里，下载完或断线时丢掉。
  - 进度和取消都在手机端：通知栏显示正在传第几个、已传多少，带"取消"按钮。手机端发出时马上提示"正在发送到 某某"，不靠横幅：澎湃 OS 只给系统白名单里的应用（微信、飞书等）弹横幅，其他应用的通知只进通知栏。进度通知安静；结果通知设为重要，在系统允许弹横幅时弹出。一次只传一批，后发的排队。
  - 断线或者任何一端出错，这一批就失败，已经传完的文件保留，没传完的删掉。手机端在通知上取消时，电脑端看到的也是上传中断，同样提示"接收中断"；不断点续传，重发一次即可。断线靠现有连接的心跳发现（ADR-0004），不用等传文件的请求超时。
- 手机端存文件用系统的媒体库：安卓 10 起不需要存储权限。安卓 9 及以下不能接收文件（电脑端发来时手机端提示"这部手机的系统版本太低，不能接收文件"，电脑端也提示），发送照常。
- 通信格式：新增电脑端告诉手机端有文件可下载的消息；协议版本加一（ADR-0010）。
- Windows 上，文件名里有 Windows 不允许的字符或者是系统保留的名字时，换成下划线再存（docs/prd/windows-desktop.md）。iOS 版再做。

## Testing Decisions

- 电脑端集成测试：带设备密钥的上传请求把文件存进指定的文件夹，并把这一批文件放进假的剪贴板；没有设备密钥或密钥不对的请求被拒；重名时加序号；上传中途断开时不留下没传完的文件，已经存好的保留并提示接收中断；电脑端发文件时只有选中的手机端收到文件清单，能按清单下载到原文件内容，手机端报告结果或者断线后清单失效；手机端报告的结果各自对应提示，取消的不提示。
- 手机端单元测试：发给当前电脑，当前电脑不在线时提示；剪贴板里是文件时先要确认；一批文件按顺序传，后发的排队；取消和失败时报告对应的结果；收到电脑端的文件清单时逐个下载，处理完把结果（存好、失败、取消、不能接收）告诉电脑端。
- 真机验证：两端"发送文件"打开的系统选文件面板和文件选择器、系统分享菜单多选、相册里"复制"的图片、访达复制和截图到剪贴板、存进相册和"下载"、通知进度和取消、传大文件时触控板不卡。

## Out of Scope

- 文件和图片的自动同步。
- 手机端"粘贴图片"。
- 文件夹（以后可以考虑打包发送）。
- 断点续传、两台电脑之间直接传文件。
- 安卓 9 及以下接收文件。
- iOS 版。

## Further Notes

- 手机端读取别的应用复制的图片时，系统会提示"EchoPad 已粘贴…"，和读文字一样。
