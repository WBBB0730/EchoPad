# typing

**打字与按键**

## Problem Statement

只靠触控板和语音输入，还不能完全离开键盘：识别出的错字需要改；有些内容不方便说出口，比如网址、代码、密码；回车、退格、方向键、复制粘贴这类按键也离不开。

## Solution

手机端提供输入框：用手机上的任意输入法打字，点发送后文字上屏到电脑的插入点。输入框下方有一排特殊键和一排快捷操作，按下立即作用于电脑。上屏方式选"先编辑"时，语音输入整理好的句子先进入输入框，改好再发送。

## User Stories

1. 作为用户，我希望打开键盘面板，在输入框里用手机输入法（包括中文）打字，点发送后文字出现在电脑的插入点。
2. 作为用户，我希望发送后输入框自动清空，方便接着输入。
3. 作为用户，我希望按回车、退格、删除、Tab、Esc、空格、方向键、Home、End、上下翻页时，电脑立即收到对应的按键。
4. 作为用户，我希望一键完成复制、剪切、粘贴、撤销、重做、全选、切换应用，不用关心电脑是 Mac 还是 Windows。
5. 作为用户，我希望上屏方式选"先编辑"时，说出的话整理后进入输入框，我改好再发送。
6. 作为用户，我希望随时在"直接上屏"和"先编辑"之间切换，并且下次打开时还记得我的选择。
7. 作为用户，我希望断线时输入框里的文字不丢，重连后可以接着发送。

## Implementation Decisions

- 输入框整段发送，不逐键同步，这样拼音等输入法组字过程中的字母不会打进电脑。
- 特殊键和快捷操作是两种独立的消息。快捷操作只描述意图，由电脑端按系统换成组合键：macOS 用 Command，重做是 Command+Shift+Z，切换应用是 Command+Tab；以后的 Windows 用 Ctrl。
- 先编辑模式：手机端开始语音输入时带上上屏方式；电脑端整理好每个定稿句后，把句子发回手机端而不上屏，手机端追加到输入框末尾。英文句子之间同样自动补空格。
- 打开键盘面板后，触控区缩小但仍可使用；先编辑模式下收到语音文字时自动打开键盘面板。
- 上屏方式保存在手机端。
- 未连接时发送按钮不可用，输入框里的文字保留。
- 电脑端用 Unicode 键盘事件输入文字，与语音输入的上屏方式相同。

## Testing Decisions

- 电脑端集成测试：打字、特殊键、快捷操作的消息会变成对应的输入命令；先编辑模式下整理好的句子发回手机端，并且不上屏。
- 手机端单元测试：先编辑模式下收到的语音文字按顺序追加到输入框。
- 联调时不在开发者自己的电脑上真实打字和按键，避免误操作；只验证手机端界面和消息收发。

## Out of Scope

- 逐键实时同步。
- 自定义快捷操作。
- 用语音指令编辑，例如"删掉上一句"。
