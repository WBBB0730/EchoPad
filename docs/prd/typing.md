# typing

**打字与按键**

## Problem Statement

只靠触控板和语音输入，还不能完全离开键盘：识别出的错字需要改；有些内容不方便说出口，比如网址、代码、密码；回车、退格、方向键、复制粘贴这类按键也离不开；看视频、听音乐时还要调播放和音量。打字时如果先在手机上打好再点发送，每次都多一步，也和在电脑键盘上打字的习惯不一样。语音输入之后最常按的是回车和退格，如果每次都要先弹出手机键盘，既多一步，又挡住半个屏幕，单手时更不方便。

## Solution

点"键盘"弹出手机键盘，打字直接上屏：在手机键盘上选定的字立即输入到电脑的插入点，组字只显示在手机端；手机键盘上的退格、回车、空格直接作用于电脑。常驻退格、回车和一排按键：默认是文本操作（撤销、重做、剪切、复制、粘贴、全选），也可以切换成其他特殊键（包括空格）或媒体键，都不用弹出手机键盘，单手也能按到。点"按住说话"左边的"修饰"多出一排修饰键：先点修饰键，再按特殊键、在手机键盘上打字或者点触控区，就是对应的组合键，单手也能按出 ⌘W、⇧+方向键、⌘+点击。

## User Stories

1. 作为用户，我希望点"键盘"弹出手机键盘，用任意输入法（包括中文）打字，选定的字立刻出现在电脑的插入点。
2. 作为用户，我希望用拼音打字时，还没选定的拼音不会打进电脑，并且能在手机上看到正在拼的内容。
3. 作为用户，我希望手机键盘上的退格、回车、空格直接作用于电脑，就像在电脑键盘上按一样。
4. 作为用户，我希望不弹出手机键盘也能按 Esc、Tab、删除、方向键、Home、End、上下翻页，电脑立即收到对应的按键。
5. 作为用户，我希望一键完成复制、剪切、粘贴、撤销、重做、全选，不用关心电脑是 Mac 还是 Windows。
6. 作为用户，我希望在手机上控制电脑的播放/暂停、上一首、下一首、音量加减和静音。
7. 作为用户，我希望打开手机键盘时，触控区和常驻的按键仍然可用。
8. 作为用户，我希望用系统返回手势收起手机键盘时，键盘按钮也恢复成没打开。
9. 作为用户，我希望按住退格、方向键或删除时像电脑键盘一样连续触发。
10. 作为用户，我希望不弹出手机键盘、单手拿手机时大拇指也能按到退格和回车。
11. 作为用户，我希望不弹出手机键盘就能撤销、复制、粘贴、全选，也能控制播放和音量。
12. 作为用户，我希望能按出快捷操作以外的组合键，比如 ⌘W 关标签页、⇧+方向键选中文字、⌥+方向键按词移动、终端里的 ⌃C。
13. 作为用户，我希望单手也能按组合键：先点修饰键，再按另一个键。
14. 作为用户，我希望连着按好几个带同一个修饰键的组合键时，不用每次重新点修饰键。
15. 作为用户，我希望修饰键也能配合触控区，比如 ⌘+点击在新标签页打开链接、⇧+点击选中一串文件。
16. 作为用户，我希望不用修饰键时它不占地方，用的时候不影响我正在用的按键组。
17. 作为用户，我希望断线、切换电脑或者别人在用这台电脑的键盘时，修饰键不会卡在电脑上一直按着。

## Implementation Decisions

- 手机键盘直通：手机端不用普通文本框，而是用 Android 官方的输入法接口直接接收输入法的输出：
  - 输入法选定的字立即作为上屏文字发给电脑端，文字里的换行转成回车；
  - 组字只显示在手机端，不发送；组字过程中的退格由输入法自己处理；输入法结束组字但没有选字时，把组字按原样上屏，和普通文本框的行为一致；
  - 没有组字时的退格、删除、回车，转成对应的特殊键；
  - 手机端不保留已上屏的文字，输入法看到的编辑区始终是空的，因此不会回头改写已上屏的词，自动纠错只作用于正在组字的内容；
  - 关闭输入法的全屏模式，横屏时也能看到触控区。
- 常驻的退格和回车：语音输入之后最常按的两个键（改错、发出），不论有没有弹出手机键盘都显示。竖屏放在"按住说话"上面那排圆形按键的右边，回车在最右边，和实体键盘上退格、回车在右边的习惯一致；横屏放在右侧一列、"按住说话"上方。手机键盘弹出时和它自带的退格、回车重复，但界面保持不变。常驻的键这一版固定，不能配置。
- 常驻的按键，每个键等宽，不论有没有弹出手机键盘都显示。竖屏一排 6 个；横屏一排 3 个、固定两排，把每组按列切成左右两块，一块一页，左右滑动翻页，方向键这样的一块不会被拆开：
  - 默认是文本操作：撤销、重做、剪切、复制、粘贴、全选，按 macOS 编辑菜单的顺序排列；
  - 选中圆形按键那排左边的"按键"或"媒体"，就换成那一组，再点一下取消选中、回到文本操作，最多选中一组。"按键"是其他特殊键，竖屏排成两排、一次全显示，照着电脑键盘排：上排 Esc、Home、End、空格、↑、Del，下排 Tab、PgUp、PgDn、←、↓、→。左边一列 Esc 在 Tab 上面，Home 和 End、PgUp 和 PgDn 各成一对，方向键是倒 T 形。翻页和删除显示成电脑键盘上印的 PgUp、PgDn、Del，"删除"容易被当成退格。退格、回车常驻，不重复放；空格放进来，不弹出手机键盘也能按。"媒体"是媒体键，一排。
  - 切换应用不常用，界面上不放。
- 按住连发：退格、方向键和删除按住超过系统的长按时间后，每 50ms 触发一次，直到松开或开始左右滑动翻页；回车、Esc、Tab 等不连发，免得按久了连发好几次。
- 键盘按钮只负责弹出和收起手机键盘，和两边的圆形按键一样高，宽度撑满中间的空位，打开时反色。
- 媒体键是特殊键的一种，用同一种消息；电脑端发送系统的媒体键事件，作用于正在播放的应用和系统音量。
- 用系统返回手势收起手机键盘时，键盘按钮也恢复成没打开。
- 快捷操作只描述意图，由电脑端按系统换成组合键：macOS 用 Command，重做是 Command+Shift+Z，切换应用是 Command+Tab；以后的 Windows 用 Ctrl。组合键里的字母按电脑当前的键盘布局找到对应的键，AZERTY、Dvorak 等布局也能用；macOS 只允许在主线程读取键盘布局，在其他线程读取会被系统直接结束进程，所以快捷操作交给主线程执行，按完再处理下一条操作，其他输入仍在输入线程里执行。
- 修饰键：
  - 按电脑的系统显示：Mac 上是 ⌃ ⌥ ⇧ ⌘，按 Apple 菜单里写组合键的顺序排；Windows 版是 Ctrl、Alt、Shift、Win。电脑端连接时告诉手机端自己的系统。
  - "修饰"按钮在"按住说话"左边，只负责显示和隐藏那一排修饰键，和"按键""媒体"互不排斥，可以同时打开。显示时一排 4 个，在常驻的按键和圆形按键那排之间。隐藏时所有修饰键都松开，免得看不见的修饰键带到下一次操作上。修饰键是否显示和每个键的状态在转屏后保持。
  - 粘滞：点一下修饰键，它就作用于下一个特殊键（包括常驻的退格、回车）、手机键盘打的下一个字，或者触控区的下一次单击、右键、拖拽，用完自动松开，可以同时点亮好几个；双击是连着两次单击，点亮的修饰键只带在第一下上，要带着修饰键双击就先锁定。用之前再点一下就取消。双击或长按修饰键锁定，之后一直生效，再点一下才松开。参照的同类应用：RealVNC Viewer 用双击锁定，Remote Mouse 用长按，Screens 两种都支持；修饰键不连发，长按没有别的用途，两种都支持不冲突。
  - 快捷操作和媒体键本身就是固定的意思，不带修饰键，也不会用掉点亮的修饰键；指针移动、滚动和缩放也一样。
  - 有修饰键点亮或锁定时，手机键盘切换成不组字的输入类型（Android 官方的输入类型，和密码框一样，输入法会换成英文键盘），打出的每个字都和修饰键一起作为组合键发出，而不是上屏文字；修饰键全部松开后恢复正常打字。字按电脑当前的键盘布局找到对应的键；大写字母自动带上 ⇧，字母的大小写在各种键盘布局上都对应 Shift；符号按它所在的键发出，要按 Shift 才能打出的符号需要用户点亮 ⇧，因为 enigo 只告诉我们符号在哪个键上，不告诉是否要按 Shift；找不到对应键的字不发送。和快捷操作一样，读取键盘布局要交给主线程执行。
  - 电脑上不一直按着修饰键：修饰键的状态只在手机端，每条按键、字、点击的消息带上当时生效的修饰键，电脑端按下修饰键、执行、再松开，在一条消息里做完。只有拖拽例外：拖拽开始时按下，结束时松开，拖拽中断线由电脑端补上松开。这样断线、切换电脑、多部手机端同时控制同一台电脑（ADR-0015），以及有人同时在用这台电脑的实体键盘时，修饰键都不会卡在电脑上（ADR-0016）。
  - 要改通信格式：按键和点击的消息加上修饰键，带修饰键的字用单独的消息（不走上屏文字的 Unicode 输入），电脑端的欢迎消息加上系统；协议版本加一（ADR-0010）。
- 未连接时按键不可用，打出的字不发送。
- 电脑端用 Unicode 键盘事件输入文字，与语音输入的上屏方式相同。
- iOS 版用 UIKit 的对应接口，第一版不做。

## Testing Decisions

- 电脑端集成测试：打字、特殊键（包括媒体键）、快捷操作的消息会变成对应的输入命令。
- 手机端单元测试：输入法的各种调用（选定文字、组字、结束组字、退格、删除、回车、带换行的文字）转成正确的消息序列，组字不发送。
- 电脑端集成测试：带修饰键的特殊键、字、点击、拖拽会变成带修饰键的输入命令；大写字母换成小写字母加上 ⇧。修饰键在电脑上按下又松开的过程依赖真实的键鼠模拟，在真机上验证。
- 手机端单元测试：修饰键的状态变化（点一下点亮、用完松开、用之前再点取消、双击或长按锁定、锁定后再点松开、隐藏那一排时全部松开），快捷操作和媒体键不用掉点亮的修饰键。
- 按住连发的时机在真机上验证，不做自动化测试。
- 有修饰键时手机键盘换成英文键盘，在 Gboard、搜狗、百度等主流输入法上实测。
- 联调时不在开发者自己的电脑上真实打字和按键，避免误操作；只验证手机端界面和消息收发。

## Out of Scope

- 先在手机上编辑再发送（ADR-0006）。
- 自定义快捷操作。
- 用语音指令编辑，例如"删掉上一句"。
- 按住 ⌘ 连按 Tab 挑应用这类要在电脑上一直按着修饰键的操作：电脑上不一直按着修饰键。
- Fn 键。

## Further Notes

- 各家输入法在编辑区为空时处理退格的方式不同（有的发退格键，有的调用删除文字的接口），两种都要处理，并在主流输入法上实测。
- 待定：是否增加"撤回上一句"。
- 待定：EchoPad 面向所有人开源发布，常驻哪些键以后可能要做成可配置，按用户反馈再定。
