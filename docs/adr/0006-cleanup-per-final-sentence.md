# 边说边整理：每个定稿句立即整理并上屏

识别服务每给出一个定稿句，就立刻交给一个响应快的小模型整理，整理完立即上屏。松开说话按钮时只剩最后一句要处理，等待时间最短。

代价是不处理跨句改口：前一句已经上屏、不再修改，后一句的纠正改不回去。句内改口在整理时处理。

整理可以关闭，关闭后定稿句原样上屏。语音文字一律直接上屏，不再提供先在手机端编辑再发送的方式：多一步确认会拖慢输入，说错的字用手机键盘上的退格修改（docs/prd/typing.md）。

## Alternatives Considered

- 说完后整段整理（Wispr Flow 的做法）：能处理跨句改口和整段排版，但第三方实测说完要等约 1.5 秒。
- 说完后整段重写（Typeless 的做法）：整理质量最高，但第三方实测说完要等约 3 秒。
- 只用识别服务自带的去语气词（语义顺滑）：几乎不用等，但只会删词，不会理顺语序。官方文档确认流式识别也支持这个参数，所以作为整理前的第一步一并开启，不替代整理。
