# 修饰键的状态只在手机端，随每条操作一起发给电脑端

修饰键在手机端是粘滞的：点亮或锁定以后，作用于之后的按键、字和点击（docs/prd/typing.md）。手机端只记着哪些修饰键生效，每条按键、字、点击的消息都带上当时生效的修饰键；电脑端收到后按下这些修饰键、执行、再松开，在一条消息里做完，电脑上从来不会因为手机端点亮了修饰键而一直按着它。唯一的例外是拖拽：拖拽开始时按下修饰键，结束时松开，拖拽中断线由电脑端补上松开，和按住的鼠标键一样处理。

这样，断线、切换电脑、手机端被关掉或转屏，都不会让修饰键卡在电脑上；一台电脑端同时被多部手机端控制时（ADR-0015），一部手机点亮的修饰键不会带到另一部的操作上，坐在电脑前用实体键盘的人也不受影响。同类远程控制应用正好有反例：RustDesk 的手机端把修饰键在电脑上按着，多次出现 Shift 卡住、点链接变成在新窗口打开的问题。

代价是做不到要一直按着修饰键的操作，比如按住 Command 连按 Tab 挑应用：每按一次 Tab，Command 都会松开一次，只能在最近的两个应用之间来回切换。

## Alternatives Considered

- 点亮修饰键时就在电脑上按下，熄灭时松开，和实体键盘完全一样：能做按住 Command 连按 Tab，但手机端的每一种离开方式（断线、切换电脑、锁屏、被系统结束）都要保证补发松开，漏一处修饰键就卡在电脑上；多部手机端和实体键盘也会互相干扰。
- 手机端把修饰键连同主键拆成按下、松开几条消息发送：本质上和上一种一样，中途断线时同样会卡住。
