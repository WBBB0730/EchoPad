# 多对多配对；手机端与所有在线的电脑端保持待命连接，连接总由手机端发起

一部手机端可以配多台电脑端（家里和公司各一台），一台电脑端也可以配多部手机端（手机和平板）。手机端打开时，与当前网络里所有配对过的电脑端各保持一条连接，其中一台是当前电脑，触控、打字和语音只发给它；默认是上次控制的那台。切换既可以在手机端的电脑列表里点，也可以在电脑端点"让这部手机控制这台电脑"：电脑端通过已有的待命连接通知手机端切换。

连接总由手机端发起。Android 应用在后台很难接收别人发来的连接，iOS 完全不允许，手机还经常换网络、开热点；而电脑端固定监听，手机端按电脑端标识就能在局域网里找到它。待命连接让电脑端也能把手机"叫过来"，效果上等于电脑端主动连手机。

多部手机端可以同时操作同一台电脑端，不区分谁在控制。电脑端按每部手机端分开记录按住的鼠标键和进行中的语音输入，一部断线不影响另一部。以后的剪贴板同步采用所有设备互相同步：每条内容带唯一编号避免来回转发，以最后复制的为准，每台设备可以单独关闭。

这推翻了此前"一台电脑端只与一部手机端配对"的做法。

## Alternatives Considered

- 一台电脑端只配一部手机端：规则最简单，但换手机、手机和平板并用都要重新扫码，手机在家和公司之间也只能记一台电脑。
- 同一时间只有一部手机端是控制者，谁最后操作谁接管：给剪贴板同步提供了明确的"当前那一部"，但多一套接管状态；改为所有设备互相同步后，不再需要它。
- 电脑端直接连接手机端：手机端要一直监听端口，后台和 iOS 上做不到，手机的地址也经常变。
