# 两端共用一个版本号，一起发版

电脑端和手机端共用一个 SemVer 版本号：一个 `vX.Y.Z` 标签同时发布两端，同一个 GitHub Release 里同时放着两端的安装包和同一份更新清单。这样 GitHub 的"最新版"链接（`releases/latest`）对两端都成立，两端的应用内更新可以读同一个固定地址，更新日志也只写一份。代价是只改了一端时，另一端的用户也会收到一次更新。

两端能不能连接，不看版本号是否相同，而是看单独的协议版本（ADR-0010），所以只改了一端时，不会逼着另一端更新才能用。

## Alternatives Considered

- 两端各自的版本号和标签（如 `desktop-v1.2.0`、`mobile-v1.3.0`）：只改了哪端就只发哪端。但 GitHub 的"最新版"同一时间只能指向一个 Release，两端都得通过 API 翻找属于自己的那个，发版流程也要拆成两套。
