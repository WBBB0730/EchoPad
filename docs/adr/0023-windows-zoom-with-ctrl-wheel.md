# Windows 上的缩放用 Ctrl 加滚轮，一档一档地缩放

Mac 上的缩放是发出和触控板捏合一样的原生手势，跟手、平滑、以指针为中心（ADR-0012）。Windows 版电脑端（docs/prd/windows-desktop.md）做不到同样的效果，改用按住 Ctrl 滚滚轮：手机端发来的缩放量每攒够一档，按下 Ctrl、滚一格滚轮、松开 Ctrl，向上滚是放大。

这是 Windows 上通行的缩放方式：浏览器、Office、图片查看器、资源管理器都认，Windows 的精确式触控板对不认手势的应用也是这样换的。Ctrl 随每一格按下、松开，不会一直按在电脑上（ADR-0016）。

代价：一档一档地跳，不跟手；浏览器里缩放的是整页，不是以指针为中心放大内容。一档对应多少缩放量是估计值，要在真机上调。

## Alternatives Considered

- 模拟触控板：微软给 Windows 11 新增了公开的模拟触控板接口（`CreateSyntheticPointerDevice2`），能发出和笔记本触控板一样的捏合，平滑、以指针为中心。但文档还标着预发布，Windows 10 和较早的 Windows 11 没有，做的时候也没有条件验证。以后可以在新系统上加这一条路，Ctrl 加滚轮仍然留给其他系统，两者不冲突。
- 模拟触摸屏的双指捏合（`InjectTouchInput`）：Windows 10 上也有，同类工具 mooz 用它在浏览器里做到了平滑缩放。但系统把这次操作当成触摸屏，触摸期间指针会隐藏；按触摸捏合缩放的应用比认 Ctrl 加滚轮的少；mooz 的作者也只在浏览器里试过，这里没有条件验证。
- 发放大、缩小的快捷键（Ctrl 加等号或减号）：和 Ctrl 加滚轮一样一档一档，但很多应用不认，也不以指针为中心。
