# 识别用云端豆包流式语音识别，声音经电脑端转发

手机端按住说话期间把录音实时发给电脑端，由电脑端调用豆包流式语音识别。选豆包是因为它在多份 2026 年的中文评测中属于第一档（与 Qwen3-ASR、Fun-ASR 的普通话字错率差距在 1 个百分点以内），并且支持热词和图片上下文，可以附带屏幕参考。

声音经电脑端转发而不是由手机直连云端，有三个原因：识别服务的密钥只存在电脑端；电脑端能附带屏幕参考；以后换成本地模型时链路不变。

代价是声音和屏幕参考都会上传到云端，识别按时长计费。

## Alternatives Considered

- 本地模型（Qwen3-ASR、Fun-ASR-Nano）：免费、离线、隐私好，准确率同档或略低；但很吃电脑算力，还要维护推理进程。保留为以后的选项。
- 手机系统自带识别（如 iOS SpeechAnalyzer）：免费，但中文准确率明显更低，也不支持自定义词汇。
- 手机直连云端：少一次转发，但密钥要放在手机上，也拿不到屏幕参考。
