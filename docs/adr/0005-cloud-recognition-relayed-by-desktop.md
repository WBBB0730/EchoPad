# 识别用云端识别服务，声音经电脑端转发

手机端按住说话期间把录音实时发给电脑端，由电脑端调用用户选择的识别服务。第一批支持豆包流式语音识别（默认）和阿里百炼的 Fun-ASR 实时识别：两者在多份 2026 年的中文评测中都属于第一档，普通话字错率与 Qwen3-ASR 的差距在 1 个百分点以内。密钥由用户自带（ADR-0007）。

豆包支持热词和图片上下文，可以附带屏幕参考。第一版的屏幕参考只附带当前应用和窗口的名称，作为文字上下文；图片上下文要等实测后再考虑。阿里百炼的上下文格式第一版暂不使用。

声音经电脑端转发而不是由手机直连云端，有三个原因：识别服务的密钥只存在电脑端；电脑端能附带屏幕参考；以后换成本地模型时链路不变。

代价是声音和屏幕参考都会上传到云端，识别按时长计费。

## Alternatives Considered

- 本地模型（SenseVoice、Qwen3-ASR、Fun-ASR-Nano）：免费、离线、隐私好，但公开评测里的字错率比云端高一档，还要先下载模型。保留为以后的选项。
- 手机系统自带识别（如 iOS SpeechAnalyzer）：免费，但中文准确率的公开数据参差不齐，也不支持自定义词汇。
- 手机直连云端：少一次转发，但密钥要放在手机上，也拿不到屏幕参考。
