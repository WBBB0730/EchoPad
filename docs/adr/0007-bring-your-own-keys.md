# 用户自带密钥，不内置密钥，也不做服务器

EchoPad 免费开放给所有人用。识别服务和整理服务的密钥由用户在电脑端的设置里自己填写，和其他设置一起保存在电脑端的设置文件里，文件只有当前用户可以读写；安装包里没有任何密钥，也没有我们自己的服务器。用户可以在几家预设的服务之间切换，整理服务还可以填任何兼容 OpenAI Chat Completions 的地址。这符合开源软件的习惯：不需要账号和付费，费用由用户直接付给云服务商，我们也不用承担服务器的运维和费用。

代价是用户得自己开通云服务、申请密钥，上手门槛更高。为了降低门槛，整理服务可以关闭，最少只需要一个识别服务的密钥。

## Alternatives Considered

- 自建中转服务器，密钥只放在服务器上：用户装上就能用，但要做账号、限量和运维，费用由我们承担，不符合"完全免费、不做复杂设计"的定位。
- 服务器只发临时凭证，电脑端直连云服务：服务器负担小，但仍然需要账号和服务器；而且语音识别的临时凭证能否用于实时识别接口，还没有确认。
- 密钥存在系统钥匙串里：比文件多一层保护，但用户希望自己管理密钥，能在设置里直接看到和复制；而且每次换签名的构建，系统都会重新弹窗要求授权读取，读取被挡住时电脑端无法正常启动。
