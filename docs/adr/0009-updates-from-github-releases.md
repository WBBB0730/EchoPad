# 两端自己从 GitHub Release 更新，不上架应用商店

两端都从公开仓库最新的 GitHub Release 更新：电脑端用 Tauri 官方的更新插件，手机端自己下载 APK，交给系统的 `PackageInstaller` 安装。用户不需要任何账号或凭证。和 DevCube 是同一套做法，也符合 EchoPad 免费、开源、不做服务器的定位（ADR-0007）。

能不能更新，靠两把钥匙：电脑端的更新包必须用 Tauri 更新签名私钥签名，应用里内置对应的公钥，签名对不上就拒绝安装；手机端则由系统核对新 APK 的签名和已装版本是否一致。这两把钥匙一旦丢了或换了，已安装的用户就无法在应用内更新，只能手动重装，手机端重装还会丢掉配对，所以必须离线备份。

代价：国内访问 GitHub 可能慢或者失败；手机端要用户允许一次"安装未知应用"。

## Alternatives Considered

- 上架应用商店：更新交给商店，最正规。但 Google Play 在国内用不了；国内商店需要软件著作权等资质，每次发版还要审核。
- 电脑端在局域网里把配套的 APK 分发给手机端：手机不用连 GitHub，两端版本天然一致。但电脑端的安装包和每次更新都要多带一个 APK，手机也只能等电脑先更新。
- 代码放私有仓库，另开一个公开仓库专门放安装包：代码不公开，但发版要跨两个仓库，还多一个长期有效的令牌要管。
- 自建对象存储或 CDN：国内下载最快，但要自己付费维护。
