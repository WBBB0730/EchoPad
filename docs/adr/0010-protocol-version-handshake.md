# 连接时核对协议版本，不兼容就拒绝连接

两端各自更新，总会有一端新、一端旧的时候。Protobuf 会默默忽略看不懂的字段和消息，旧的一端不会报错，用户只会看到新功能没反应。所以 `echopad.proto` 定义一个整数协议版本，手机端在 `Hello` 里带上。电脑端先核对版本、再验证配对：不一致就拒绝连接，并告诉手机端自己的协议版本，两端都提示更新较旧的那一端。版本不兼容时配对保留，也不消耗配对口令，更新之后自动连上。

协议版本只在一端需要理解另一端的新内容时加一，比如新增或删除消息、字段，或者改变了含义。

## Alternatives Considered

- 比较应用版本号：两端共用一个版本号（ADR-0008），每次发版两端的版本号都会变。如果要求版本号相同，只改了一端也会逼着另一端更新才能用。
- 只提示、不拒绝：旧功能还能继续用，但新功能照样默默失效，问题并没有解决。
- 不核对，只靠 Protobuf 自身的前后兼容：这正是现在的问题。
